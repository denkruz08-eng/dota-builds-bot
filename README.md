# Dota Builds Bot (Telegram)

> **Работа 24/7 без ПК:** используется бесплатный GitHub Actions —
> `.github/workflows/bot.yml` (запуск каждые 6 часов на 5 ч 50 мин, токен в
> секрете `BOT_TOKEN`). Папка для загрузки в репозиторий — `deploy_upload/`.
> Альтернативы: платный Bothost — [`deploy/BOTHOST.md`](deploy/BOTHOST.md),
> VPS — [`deploy/README.md`](deploy/README.md).
>
> Если dotabuff блокирует IP сервера (403), карточка героя автоматически
> берётся из OpenDota API (`opendota.py`), список героев — из
> `heroes_static.json`, гайды заменяются про-билдами D2PT.

Телеграм-бот со сборками по Dota 2 для всех героев. Источники:

- [dota2protracker.com](https://dota2protracker.com/) — про-билды **по позициям
  Pos 1–5** (стартовые предметы, кор-предметы с таймингами, финальный
  инвентарь, порядок прокачки способностей, таланты, винрейт про-матчей)
- [dotabuff.com](https://www.dotabuff.com/) — карточка героя (винрейт, лейны,
  популярные предметы недели, контрпики) и топ-гайды недели
- [OpenDota API](https://www.opendota.com/api) — мета по рангам, матчапы
  для контр-пика, разбор матчей

## Что умеет

- **Выбор героя** — список всех героев (127+) или поиск по-русски/по-английски
  (`пудж`, `па`, `инвок`, `tinker`, `invoker`, …)
- **Карточка героя — сразу постер**: при выборе героя приходит готовая
  картинка 1080×1350 для сторис — портрет, роли, винрейт, сильные и слабые
  противники, топ-3 сборки по позициям с винрейтом (D2PT), полная сборка
  лучшей позиции (старт, кор с таймингами, прокачка, таланты) и финальный
  инвентарь с фотками; под ней короткая подпись и кнопки сборок по позициям
- **🩹 Патчноуты по герою** — кнопка «🩹 Патч» в карточке: полный список
  изменений героя в актуальном патче (база, способности, таланты) из
  официального фида dota2.com; число изменений видно сразу под постером
- **Выбор героя картинками** — сетка портретов с именем под каждым героем,
  плюс кнопки для выбора
- **Красивый стартовый экран** — анимированный баннер 1280×720, 60 fps, ~9 секунд,
  бесшовный луп (исходник — 2K-апскейл, конец плавно переходит в начало;
  отправляется как Telegram animation и крутится без остановки);
  если `start_anim.mp4` нет — обычный PNG. Компактное меню снизу
  (Выбрать героя / Поиск / Мета / Контр-пик / Герой дня / Разбор матча /
  Главное меню)
- **Сборка от игрока** — у Lone Druid правая колонка постера заменяется
  компактной сборкой из гайда Steam (до 10 минут, по порядку, по ситуации,
  late и ситуативные предметы — одними иконками); в подписи — автор сборки
  @tgkpyatka69 и ссылка на гайд; для остальных героев всё как обычно (D2PT)
- **Навигация без свалки сообщений** — список героев листается в том же
  сообщении (без удаления и мигания), остальные экраны заменяют друг друга
  на месте
- **Про-билд по позиции** — кнопки 🏹 Pos 1 Carry / 🎯 Pos 2 Mid /
  🛡 Pos 3 Off / 🧙 Pos 4 Soft Sup / 💉 Pos 5 Hard Sup / 📊 All
  (источник — Dota2ProTracker, статистика про-матчей):
  - 📈 число про-матчей и винрейт по позиции
  - 🎒 стартовые предметы (самый популярный закуп)
  - 🧭 кор-предметы с таймингами (`Magic Wand (4м) → Kaya (9м) → …`)
  - 🏁 финальный инвентарь (six slot)
  - ⚡ порядок прокачки способностей
  - 🌟 самые популярные таланты на 10/15/20/25
  - 🖼 картинка-сетка с иконками предметов (старт / кор с таймингами / финал)
- **📖 Dotabuff Guides** — топ-выступления недели с dotabuff (стартовые
  предметы, билд с таймингами, скилл-билд, ссылка на матч)
- **🩹 Актуальный патч** — на стартовом экране и в каждой сборке; берётся из
  фида dota2.com (страница [/patches](https://www.dota2.com/patches/)),
  обновляется в фоне каждые 3 часа
- **📊 Мета патча по MMR** — готовый постер 1080×1350: топ-10 героев
  по винрейту и по популярности с портретами для выбранного ранга
  (🌐 Все ранги, Herald, Guardian, Crusader, Archon, Legend, Ancient, Divine
  с диапазонами MMR), саммари по матчам и OpenDota; обновление раз в час
- **⚔️ Контр-пик по драфту** — пишешь героев врага (`pudge, invoker, am`),
  бот считает по матчап-статистике OpenDota, кто против них сильнее всего,
  и показывает преимущество в процентах по каждому врагу + кнопки на карточки
- **🎲 Герой дня** — один и тот же герой в течение суток (по МСК): карточка
  и про-билды; повод заходить каждый день
- **📈 Разбор матча** — пришли номер матча: счёт по киллам, башни/Рошан,
  первая кровь, урон и нетворс команд, переломный момент по графику золота,
  крупнейший файт, MVP; кнопкой выбираешь своего героя — перцентили на герое
  (GPM, XPM, добивания, урон, выживаемость) и подсказки «что улучшить»;
  плюс картинка с финальными сборками всех 10 игроков
- **⬅️ Назад** — из любого билда/гайдов обратно в карточку героя

Данные кешируются: билды — 1 час, список героев — 24 часа (в памяти и в
файле `heroes_cache.json`, так что поиск работает даже если сайты тупят).

## Запуск

1. Получи токен у [@BotFather](https://t.me/BotFather) в Telegram
   (команда `/newbot`).

2. Установи зависимости:

   ```
   pip install -r requirements.txt
   ```

3. Укажи токен — любым из способов:
   - создай файл `token.txt` рядом с `bot.py` и вставь туда токен;
   - или задай переменную окружения `BOT_TOKEN`.

4. Запусти бота:

   ```
   python bot.py
   ```

5. В Telegram найди своего бота, нажми `/start` — и выбирай героя.

## Команды

| Команда   | Что делает                          |
|-----------|-------------------------------------|
| `/start`  | главное меню                        |
| `/heroes` | список всех героев                  |
| `/search` | поиск героя по имени                |
| `/meta`   | мета патча по MMR-рангам            |
| `/counter`| контр-пик по драфту врага           |
| `/daily`  | герой дня                           |
| `/match`  | разбор матча по номеру              |

Также можно просто написать имя героя в чат — бот поймёт.

Помимо команд есть компактное меню снизу (над полем ввода):
**🛡 Выбрать героя** · **✍️ Поиск героя** · **📊 Мета патча** ·
**⚔️ Контр-пик** · **🎲 Герой дня** · **📈 Разбор матча** ·
**🏠 Главное меню**, а в кнопке «Menu» слева от поля ввода — те же команды
списком.

## Прокси (обход блокировок Telegram)

Если провайдер режет доступ к `api.telegram.org`, бот умеет ходить в Telegram
через SOCKS5/HTTP-прокси (например, локальный порт VPN-клиента вроде v2rayN):

- создай файл `proxy.txt` рядом с `bot.py` со строкой вида
  `socks5://127.0.0.1:10808`
- или задай переменную окружения `BOT_PROXY`
- требуется пакет `aiohttp-socks` (есть в `requirements.txt`)

Важно: прокси используется **только для Telegram**. Сайты dotabuff и d2pt
работают напрямую — Cloudflare dotabuff отдаёт 403 на выходные IP прокси.
Если понадобится, сайты можно отдельно проксировать переменными
`DOTABUFF_PROXY` и `D2PT_PROXY`.

Для стабильности используется ротация IP серверов Telegram (пул
`TG_CANDIDATE_IPS` + переопределение DNS), ретраи сетевых ошибок и
авто-перезапуск поллинга.

## Premium-эмодзи (custom emoji)

Обычный «подарок Premium» боту не работает. По официальной документации
Bot API custom emoji может использовать только бот, **купивший
дополнительный юзернейм на Fragment**
(`Custom emoji entities can only be used by bots that purchased additional
usernames on Fragment`).

Порядок:
1. [fragment.com](https://fragment.com/usernames) — подключить TON-кошелёк
   и Telegram, купить любой доступный юзернейм.
2. Назначить купленный юзернейм боту (`Assign to Bot`).
3. После этого бот может отправлять эмодзи через
   `<tg-emoji emoji-id="...">👍</tg-emoji>`.

ID эмодзи бот умеет собирать сам: пришли ему сообщение с премиум-эмодзи —
он ответит списком `custom_emoji_id`. В коде за это отвечает
`tg_emoji(char, emoji_id)`.

## Файлы

- `bot.py` — логика бота (aiogram 3)
- `dotabuff.py` — скрапер dotabuff.com (curl_cffi для обхода Cloudflare,
  BeautifulSoup для парсинга, кеш с TTL, дисковый кеш списка героев)
- `d2pt.py` — скрапер dota2protracker.com (билды по позициям Pos 1–5)
- `items_img.py` — иконки предметов (CDN Valve) и портреты героев (d2pt),
  сборка картинок-сеток для Telegram (сетка героев, предметы билда,
  финальные сборки матча) и постер 1080×1350 для шаринга; кеш в `icons/`
- `patch.py` — актуальный патч Dota 2 с dota2.com (кеш 6 ч, фолбек
  `patch_static.json`) + заметки патча по герою (`hero_changes`)
- `heroes_ru.json` — русские названия героев и алиасы для поиска
- `token.txt` — сюда кладётся токен бота (не коммитить!)
- `proxy.txt` — сюда кладётся адрес прокси (не коммитить!)

## Источники данных

- [OpenDota API](https://www.opendota.com/api) — мета по MMR-рангам,
  матчапы для контр-пика, разбор матчей
- [dotabuff.com](https://www.dotabuff.com/) — карточка героя и гайды

Бот бесплатный, без рекламы и продажи данных. Фан-проект, не связан с Valve,
Dotabuff и OpenDota; права на данные и изображения принадлежат их владельцам.
Короткий дисклеймер показывается в `/start`.

## Примечания

- Имена героев, лейны и позиции в кнопках — на английском (Mid / Carry /
  Offlane / Support / Jungle, Pos 1–5), остальной текст — на русском.
- Названия предметов остаются на английском (как на сайтах-источниках).
- Слуги страниц d2pt — имя героя с `+` вместо пробелов
  (`/hero/Shadow+Fiend/builds`, `/hero/Nature's+Prophet/builds`).
- Если dotabuff временно блокирует запросы (403/429), бот делает ретраи;
  при неудаче просто повтори запрос позже.
