# Dota 2 Builds Bot

Telegram-бот со сборками по Dota 2: карточка героя с dotabuff и
про-билды по позициям Pos 1–5 с dota2protracker.

## Что умеет

- Выбор героя сеткой портретов (127 героев) или поиск по имени
- Карточка героя: винрейт, лейны, частые предметы, контрпики
- Про-билды по позициям: старт, кор с таймингами, финальный инвентарь
- Скилл-билд, таланты, иконки предметов картинкой
- Гайды с dotabuff по ролям

## Запуск

```bash
pip install -r requirements.txt
export BOT_TOKEN=123456:ABC...   # токен от @BotFather
python bot.py
```

Без переменной `BOT_TOKEN` бот ищет файл `token.txt` рядом с `bot.py`.

Опционально: `BOT_PROXY=socks5://host:port` — прокси для Telegram,
`DOTABUFF_PROXY` — прокси для dotabuff.

## Файлы

| Файл | Назначение |
|------|------------|
| `bot.py` | хендлеры aiogram, меню, карточки |
| `dotabuff.py` | скрапер dotabuff (карточка героя, гайды) |
| `d2pt.py` | скрапер dota2protracker (про-билды по позициям) |
| `items_img.py` | иконки предметов/портреты, сборка картинок |
| `heroes_ru.json` | русские названия героев |
| `assets/fonts` | шрифты для картинок (одинаково на любой ОС) |

## Деплой на Bothost (бесплатно)
